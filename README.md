# 🩺 Healthcare Website

A modern, responsive healthcare website built using **Next.js 15** and **Tailwind CSS**, designed for a professional medical and psychiatry business.  
The website provides information about the clinic, its services, team, and appointment booking through **Calendly integration**.

---

## 🚀 Tech Stack

- **Next.js 15 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Vercel Deployment**
- **Calendly Integration**

---

## 📄 Pages

The website includes up to **10 pages**, covering all essential sections for a healthcare business:

1. Home  
2. About  
3. Services  
4. Conditions / Treatments  
5. Team / Providers  
6. FAQs  
7. Testimonials  
8. Contact (with Calendly appointment booking)  
9. Privacy Policy  
10. Blog / Additional Info (optional)

---

## 🧩 Features

- Responsive design for all screen sizes  
- Smooth navigation using Next.js App Router  
- Reusable UI components (Hero, Cards, Accordions, etc.)  
- Optimized images and clean layout  
- Easy content management through data files (`/data/`)  
- Deployed on **Vercel** for fast and secure hosting  

---

## 📅 Project Scope

This project was built as a **freelance healthcare business website** inspired by [Blue Sky Psychiatrists](https://www.blueskypsychiatrists.com/).  
It focuses on presenting the clinic’s details, services, and professional staff while simplifying the appointment scheduling process.

---

## 🔗 Calendly Integration

Appointments are handled through an embedded **Calendly widget**, allowing patients to schedule sessions directly from the website.
